# ORBIT

仕事をする上で、生きていく上で。人間関係やコミュニケーションのこと、毎日の仕事が少し進めやすくなること。そういう本を選んで、週に一冊ずつお届けします。

公開: https://sword-one.github.io/diary/

## 構成

```
index.html        トップ（宇宙 ＋ 記事一覧 ＋ このサイトについて）
coaching.html     新 コーチングが人を活かす
power.html        パワーか、フォースか 改訂版
style.css         全ページ共通
img/              画像
```

## トップの宇宙

第一画面は銀河。**惑星＝カテゴリ**で、選ぶとその惑星のまわりを本が回る。
本をタップすると要約パネルが開く。

```
銀河（惑星が5つ） → 惑星を選ぶ → 本が周回 → 本を選ぶ → 要約パネル
```

### 本を足す

`index.html` の `BOOKS` の先頭に1つ追加し、**`p:` にカテゴリIDを書く**だけ。

```js
{ n:'#03', cat:'コミュニケーション', p:'comm', title:'…', cover:'img/xxx_sm.webp',
  url:'xxx.html', katch:'…', pop:{h,b,s}, sum:[…] }
```

同じ本を `SOON` に書いていたら、そちらの行は消す。

| カテゴリID | 惑星 |
|---|---|
| `comm` | コミュニケーション（青） |
| `think` | 考え方（橙・環あり） |
| `habit` | 習慣（緑） |
| `team` | チーム（紫） |
| `self` | 自分（桃・環あり） |

カテゴリを増やすときは `PLANETS` に1つ足し、`P_SLOTS_W` / `P_SLOTS_N` にも座標を1つ足す。

### 並び方

- **3冊までは手前の弧（30°〜150°）** に並ぶ。真上に置くと惑星の裏に隠れるため
- 4冊以上で一周する。奥のものは自動で小さく薄くなる
- `sum` は3〜4行の要約。**ここだけ読んでも中身が残る濃さ**にする
- `pop` は手書きPOPの画像（`img` と `alt`）。作り方は `../CLAUDE.md` §4 を見る。
  **altに画像内の文章をそのまま入れること**（読み上げと検索に残すため）

### 惑星の見た目

**CSSのグラデーションではなく、canvasで球を描いている。**
円の各ピクセルから球面の経緯度を逆算して帯模様を拾い、そこへ光のあたり方と
周縁減光（ふちが暗くなる）を掛けている。1回描いたら画像なので、毎フレームの負荷はない。

`PLANETS[].look` で変わる。

| | |
|---|---|
| `bands` | 極から極への色。`[緯度(-1〜1), 色]` を並べる |
| `turb` | 帯のゆらぎ。**0にするとまっすぐな縞になって一気に作り物に見える** |
| `detail` | 細かい乱流 |
| `spot` | 大赤斑のような渦。`{lon, lat, rx, ry, col, a}` |
| `cap` | 極冠。0で無し、0.7くらいで白い極 |
| `ring` | 1でリング。球の後ろ半分→球→手前半分の順に描いている |
| `g` | まわりの大気の光の色（CSSに渡すRGB） |

### 銀河の画面に出る書影

惑星のまわりに、その惑星の**新しい本を3冊まで**小さく出す（`moonsHTML()`）。
位置は `MOON_POS`（球の幅に対する %）。
**実際にある書影だけ出す。** 空の枠を混ぜると不具合に見えたのでやめた。

### 背景

渦巻銀河・星雲・明るい星は**作り置きした画像を貼るだけ**（毎フレーム描かない）。
画面外とタブ非表示では描画を止める。`prefers-reduced-motion` では全部止まる。

- 銀河の形は `buildGalaxy()`。腕の数・粒の数・`turns`（巻き）で変わる
- 腕のピンクの粒は星がうまれている場所。**これを消すと一気に安っぽくなる**
- 位置と大きさは `build()` の `GAL.x / GAL.y / GAL.size`、傾きは `GAL.tilt / GAL.flat`
- 星雲を強くしすぎると宇宙に見えなくなる（`buildNebula()` の `blobs`、4つ目が強さ）

**`.sheet[hidden]{display:none}` を消さないこと。** `hidden` 属性はUAスタイルなので
author側の `display:flex` に負ける。消すと透明なパネルが画面を覆い、
トップのクリックが全部吸われる（実際にハマった）。

## 記事を出したら必ずやること

```bash
python tools/gen-meta.py
```

`sitemap.xml` / `robots.txt` / `feed.xml`（RSS）を**記事HTMLから作り直す**。
別に一覧を持つと必ずズレるので、記事そのものを情報源にしてある。
日付は記事の `.by-meta` から、要約は帯から拾う。

あわせて記事側に手で足すもの:

- `<link rel="canonical">` … そのページの正規URL
- `application/ld+json` … 構造化データ（Article／about に Book）
- スキップリンク `<a class="skip-link" href="#s1">本文へ移動</a>`

`coaching.html` を複製すれば全部ついてくる。**URLとJSON-LDの書き換えを忘れないこと。**

## 壊れないようにしてあるところ

| | |
|---|---|
| JSが動かない | `<noscript>` で宇宙を畳み、記事一覧だけ見せる |
| JSが途中で落ちた | トップのスクリプト全体が `try/catch`。失敗したら宇宙を消してヘッダーを出す |
| 存在しないURL | `404.html`。**パスは `/diary/` 始まり**（深いURLでも解決するため）。ローカルでは画像が出ないが正常 |
| 文字の濃さ | 白背景の `--grey` は WCAG AA（4.5:1）を満たす `#6B7483`。**薄くしないこと** |
| キーボード操作 | 要約パネルは Tab が中だけを回る（フォーカス閉じ込め） |
| 読み上げ | `#live` に惑星の選択を通知する |
| 動きが苦手な人 | `prefers-reduced-motion` で星も惑星も止まる |
| 印刷 | 宇宙・目次・ヘッダーを隠し、リンクのURLを括弧で出す |

## ファイル名のルール

**URLに番号を入れない。** 配信の順番を入れ替えてもURLが変わらないようにするため。

- 書名から短く取る（`coaching.html` `power.html` `peptalk.html`）
- 似た書名の本が来たら、区別できる語を足す
  （例: 旧版の『コーチングが人を活かす』を扱うなら `coaching-old.html`）
- 記事中の「#01」「#02」は**表示だけ**。入れ替えたらそこだけ手で直す

## 新しい記事を追加するとき

1. `coaching.html` を複製して `<書名>.html` にする
2. 本文を書き換える
3. **帯（`.catch` ＋ `.catch-sub`）を書く。** h1のすぐ下に2行。
   **山口の言葉で書く。** 出版社のコピーや部数は帯に入れず、書籍カードへ。
   リード文（`.lede`）は置かない
4. **著者の経歴は記事末の `.bio` へ。** 冒頭の見出しは「この本は、何の本か」
5. **OGPを3つとも書き換える**（`og:title` / `og:description` / `og:url`）
   `og:description` はキャッチコピーから始める
6. ヒーロー画像とヒーローの `alt`、書影、Amazonリンクを差し替える
7. `index.html` の「記事」に1件足す（`.e-c` にキャッチコピー）。「これから」から該当行を消す
8. `git add -A && git commit && git push` → 2〜3分でPagesに反映

書き方・デザインの決まりは `../CLAUDE.md` を参照。
